About QR Motors

A student web project for buying and selling cars in Palestine.

Who We Are

QR Motors is a web platform designed to help users in Palestine browse, compare, and sell cars easily. The website includes cars from different Palestinian cities such as Nablus, Ramallah, Gaza, Hebron, Jerusalem, Jenin, and Bethlehem.

Project Idea

The idea of this project is to make the process of finding a suitable car easier by using organized pages, car filters, featured cars, trusted dealers, comparison tools, and an admin dashboard.

Project Goals

The project aims to provide a simple, organized, and user-friendly website where users can explore cars by city, brand, price, year, fuel type, and transmission.

Easy Search

Users can search cars by name, city, brand, and fuel type.

Compare Cars

Users can compare two cars before making a decision.

Admin Control

The admin can manage cars, requests, dealers, and messages.

Trusted Dealers

The website shows selected car dealers from different cities.

Our Mission

To create a modern and simple car marketplace that helps people in Palestine find the right car with clear information and organized features.
