QR Motors — University Web Project

HOW TO RUN
1. Extract the ZIP file.
2. Open index.html in a modern browser.
3. Create a customer account or use the administrator demo account.

ADMIN DEMO
Username: admin
Password: QRMotors@123

MAIN FEATURES
- Responsive navigation and dark mode
- Customer registration and login
- Search, brand/category/fuel filters, sorting, and pagination
- Car details, comparison, favorites, and finance estimator
- Purchase, sell-car, and contact requests
- Customer activity and administrator dashboards
- CSV inventory export
- localStorage-based demo persistence

IMAGES
The project runs without external images by displaying branded QR Motors
fallback artwork. Optional real images can be placed inside an img folder.
Supported extensions: jpg, jpeg, png, webp, jfif, and avif.

NOTE
This is a front-end university prototype. Production authentication should
use a secure server, a database, and hashed passwords.
